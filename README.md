# Watchlist

Eigene Watchlist mit Live-Kursen und TradingView-Chart. Es ist eine einzige Datei (`index.html`) und läuft auf GitHub Pages.

- **Symbol hinzufügen:** oben eintippen im Format `BÖRSE:KÜRZEL`, z. B. `NASDAQ:AAPL`, `XETR:SAP`, `EURONEXT:ASML`, `LSE:GAW`
- **Chart öffnen:** auf eine Zeile in der Liste klicken
- **Sortieren / löschen:** Maus über die Zeile, dann ▲ ▼ ✕
- **Viele auf einmal:** „Liste bearbeiten“ (ein Symbol pro Zeile)
- **Auf anderem Gerät:** „Link kopieren“ und als Lesezeichen speichern, die Liste steckt im Link

Daten: TradingView-Widgets. Je nach Börse sind sie Echtzeit oder etwa 15 Minuten verzögert.
